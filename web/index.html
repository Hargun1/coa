HOW THE LEARNER DECIDES

Learn from the past.
Measure what happens next.

A small logistic model scores the likelihood that each eviction candidate will be reused. Its features describe recency, decayed frequency, the previous access interval, and reuse history.

Labels mature only after the reuse horizon has passed. The frozen variant stops learning after warmup; the recency variant removes the other features.

This is a scaled, serial cache model. It does not measure real CPU speedup, hardware inference cost, page faults, or operating-system migration. The learner can lose to conventional policies.
